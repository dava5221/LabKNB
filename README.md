# LabKNB — симулятор турнира «Камень, ножницы, бумага»

Учебная консольная программа на Java, которая проводит турнир по игре «Камень, ножницы, бумага».

## Возможности

- случайная жеребьёвка участников;
- турнир на 16 или 32 участника по олимпийской системе;
- каждый матч идёт до трёх побед одного из участников;
- в конце выводится чемпион и статистика выборов.

## Технологии

- Java 14 или новее;
- стандартная библиотека Java (`Random`, `Scanner`).

## Запуск

Открой проект в IntelliJ IDEA и запусти класс `LabKNB.KNB`. Исходный файл должен находиться в каталоге `src/LabKNB/KNB.java`.
